Hand Gesture Detection

Project Description

Hand Gesture Detection is a project designed to detect and track hand movements using a computer vision approach.

Technologies Used

- Python
- HTML
- Computer Vision

Project Files

- "controller.py" – Python controller for hand tracking.
- "index.html" – Web interface for the project.

How to Run

1. Download or clone this repository.
2. Install the required Python libraries.
3. Run "controller.py".
4. Open "index.html" in a browser if required by the project.

Future Improvements

- Improve gesture recognition accuracy.
- Add support for more hand gestures.
- Improve the user interface.
